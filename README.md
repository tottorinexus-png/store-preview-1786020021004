# レストラン ビリーブ 営業提案用デモ

## 概要
鳥取県鳥取市湖山町北の「レストラン ビリーブ」を想定した、1ページ型の営業提案用デモサイトです。

この制作物は店舗公式サイトではありません。2026年8月6日時点のWeb調査結果をもとに、確認できた情報と未確認情報を分けて構成しています。

## ファイル構成
- `index.html`: ページ本体、メタ情報、構造化データ
- `style.css`: レスポンシブデザイン、配色、レイアウト
- `script.js`: スマートフォンメニュー、住所コピー、表示アニメーション、西暦表示
- `README.md`: 調査内容、差し替え手順、公開前確認事項

## デザイン方針
Web上の店舗紹介・口コミでは、オムライス、洋食の種類、食べ応えに関する言及が多く見られました。そのため、一般的な高級レストラン調ではなく、親しみやすい街の洋食店を想起させるデザインにしています。

- クリーム色: 洋食店の温かさと見やすさ
- 赤: ソースや食欲を想起させる主色
- 黄色: 卵料理を連想させる差し色
- 緑・濃色: 情報整理とコントラストの補助
- 写真が未許諾のため、料理・店内・外観を示す専用の仮画像枠を使用
- 意味のない大型英語、点滅、強いドロップシャドウ、過剰な装飾は不使用

## 営業時間を掲載していない理由
第三者サイト間で次のような表記差があり、公式Instagramの投稿内容を検索環境から直接確認できなかったためです。

- 11:30〜21:00とする掲載
- 12:00〜15:30、17:00〜21:00とする掲載
- 水曜定休とする掲載は複数あるものの、現在の公式告知としては未確認

公開前に店舗へ確認し、確定後に `index.html` の以下を更新してください。

1. ヒーロー下のクイック情報
2. 店舗情報欄の営業時間・定休日
3. 必要に応じて構造化データへ `openingHoursSpecification` を追加

## 写真差し替え
外部サイトやInstagramの写真は転載せず、すべて仮画像枠にしています。

差し替え候補:
- メインビジュアル: 店舗の代表料理または店内
- ギャラリー大: おすすめ料理
- ギャラリー小1: 店内
- ギャラリー小2: 外観・入口
- OGP画像: 横1200px × 縦630px推奨

写真は店舗所有データ、または撮影者からWeb掲載許可を得たデータのみ使用してください。料理写真については、現行メニューであることも確認してください。

## 動作確認の目安
- 320px以上のスマートフォン幅で横スクロールがないこと
- メニューボタンの開閉とEscapeキー操作
- `tel:` リンクから電話アプリが起動すること

- 住所コピーボタンがHTTPS環境とローカル環境の両方で動作すること
- ブラウザのコンソールにJavaScriptエラーがないこと
- キーボード操作時にフォーカス位置が見えること
